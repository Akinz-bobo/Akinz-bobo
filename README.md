# Adeyemo Akinola

**Senior Software Engineer and CTO.** I build and run backend systems where mistakes cost money: payments, bookings, fraud detection and the cloud infrastructure underneath them.

Six years shipping production software for companies in the US, UK and Nigeria. Currently CTO at Automaark, leading the engineering team behind a US rental marketplace.

## What I work on

| Area | What that has meant in practice |
|---|---|
| **Fintech and payments** | Concurrency-safe transactions, refund engines, ledgers, reconciliation against payment providers, payouts and bank withdrawals |
| **Distributed systems** | Event-driven backends, transactional outbox with change data capture, idempotent consumers, queues and dead-letter handling |
| **Security** | Role and attribute-based access control, audit trails, key rotation, rate limiting, and finding and fixing real vulnerabilities in production code |
| **Cloud and DevOps** | AWS and Azure, Docker, CI/CD with zero-downtime deployments, monitoring and alerting with Prometheus, Grafana and Loki |
| **Applied AI** | Retrieval (RAG) pipelines, structured-output LLM features, voice and WhatsApp assistants in four languages |
